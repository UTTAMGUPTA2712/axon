Got Questions?

Frequently Asked Questions

Everything you need to know about Axon, privacy, and API key management.

Is Axon free to use?
Yes! Axon is 100% free and open-source. You bring your own API key from providers like Google Gemini (which offers generous free tiers), Groq, or OpenAI.
Where are my API keys stored?
Your API keys are stored locally inside Chrome's isolated chrome.storage.sync storage. They never touch any middleman servers and are sent only directly to the AI provider endpoint you configured.
Which AI models does Axon support?
Axon currently supports Google Gemini (Gemini 2.0 Flash / Pro), Groq (Llama 3.3 70B), and OpenAI (GPT-4o / GPT-4o-mini). You can assign different models for Chat, Vision, and Intent routing.
Does Axon track my browsing history or screen data?
No. Axon only captures active tab screen content or selected text when you explicitly invoke the assistant via shortcut, context menu, or action button.
